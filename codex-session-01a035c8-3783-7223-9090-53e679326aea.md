# Air-Gapped Corporate Rust Development Image

## Summary

Create one multi-target Dockerfile with two independent build paths:

- `bootstrap`: built externally with public access, then exported into the air gap.
- `corporate`: built inside the air-gapped network from the imported bootstrap image. It installs corporate CAs and configures reachable internal Cargo registries.

The internal sparse registry mirror—not the image itself—is the complete dependency store. Running containers will never require crates.io.

## Implementation Changes

- The external `bootstrap` target will:
  - Use pinned `rust:${RUST_VERSION}-slim-bookworm`, defaulting to Rust `1.97.1`.
  - Install common native development packages.
  - Add `rustfmt`, `clippy`, `rust-analyzer`, and local Rust documentation.
  - Create a configurable non-root `developer` user and `/workspace`.
- The independent `corporate` target will:
  - Start from `BOOTSTRAP_IMAGE`, referring to the image loaded into the air gap.
  - Copy all `certificates/*.crt` files into Debian’s trust store and run `update-ca-certificates`.
  - Fail the build when no corporate certificates are supplied.
  - Copy the global Cargo configuration into `/usr/local/cargo/config.toml`.
  - Validate that both internal registry index URLs were provided.
  - Avoid all `apt`, rustup, crates.io, and other public network operations.
- Cargo configuration will:
  - Transparently replace `crates-io` with the internal sparse registry named `corp-mirror`.
  - Define `corp-private` for private crates and make it the default publishing registry.
  - Use Cargo’s `cargo:token` credential provider.
  - Keep credentials out of files and image layers.
- Git dependencies will not be supported. Projects must publish all dependencies into one of the internal Cargo registries.
- Expand `README.md` with the two-step build, transfer, CA installation, registry authentication, and container-run workflow.

## Build and Runtime Interface

- External bootstrap build arguments:
  - `RUST_VERSION=1.97.1`
  - `DEV_UID=1000`
  - `DEV_GID=1000`
- Corporate build arguments:
  - `BOOTSTRAP_IMAGE=rust-dev-bootstrap:1.97.1-bookworm`
  - `CRATES_IO_MIRROR_INDEX` — required `sparse+https://…/` URL.
  - `PRIVATE_REGISTRY_INDEX` — required `sparse+https://…/` URL.
- Corporate input directory:
  - `certificates/*.crt`, with one public CA certificate per file.
  - Private keys must never be placed in this directory.
- Runtime credentials:
  - `CARGO_REGISTRIES_CORP_MIRROR_TOKEN`
  - `CARGO_REGISTRIES_CORP_PRIVATE_TOKEN`
- Stable Cargo registry names:
  - `corp-mirror`
  - `corp-private`

3. Importing it with `docker load` inside the air gap.
4. Adding the corporate CA files.

      ## Build workflow
      
      The Dockerfile contains two independent targets. Build `bootstrap` on an
      internet-connected machine, transfer that image into the air gap, and build
      `corporate` there. The corporate build requires BuildKit so the unrelated
      public bootstrap stage is skipped.
      
      ### 1. Build and export the bootstrap image
      
      Run this outside the corporate network:
      
      ```sh
      docker buildx build --load \
        --target bootstrap \
        --build-arg RUST_VERSION=1.97.1 \
        --build-arg DEV_UID=1000 \
        --build-arg DEV_GID=1000 \
        --tag rust-dev-bootstrap:1.97.1-bookworm \
        .
      
      docker save \
        --output rust-dev-bootstrap-1.97.1-bookworm.tar \
        rust-dev-bootstrap:1.97.1-bookworm
      
      sha256sum rust-dev-bootstrap-1.97.1-bookworm.tar \
        > rust-dev-bootstrap-1.97.1-bookworm.tar.sha256
      ```
      
      Transfer both the tar archive and checksum through the approved import
      process.
      
      ### 2. Load the bootstrap image inside the air gap
      
      ```sh
      sha256sum --check rust-dev-bootstrap-1.97.1-bookworm.tar.sha256
      docker load --input rust-dev-bootstrap-1.97.1-bookworm.tar
      ```
      
      The name supplied through `BOOTSTRAP_IMAGE` in the next step must match the
      loaded image tag.
      
      ### 3. Add corporate CA certificates
      
      Place each corporate root or intermediate CA certificate in `certificates/` as
      an individual PEM-encoded file ending in `.crt`. Only public certificates
      belong there; never add a private key.
      
      The corporate target installs these files into Debian's system trust store.
      The build intentionally fails if the directory contains no `.crt` files.
      
      ### 4. Build the corporate image
      
      Run this inside the air-gapped corporate network. Sparse registry URLs must
      start with `sparse+https://` and end with `/`.
      
      ```sh
      docker buildx build --load \
        --target corporate \
        --build-arg BOOTSTRAP_IMAGE=rust-dev-bootstrap:1.97.1-bookworm \
        --build-arg CRATES_IO_MIRROR_INDEX=sparse+https://cargo.example.corp/crates-io/index/ \
        --build-arg PRIVATE_REGISTRY_INDEX=sparse+https://cargo.example.corp/private/index/ \
        --tag rust-dev-corporate:1.97.1 \
        .
      ```
      
      This step performs no package installation and does not fetch crates. It only
      uses the imported bootstrap image, installs the corporate CA certificates, and
      records the internal registry endpoints.
      
      ## Run the development container
      
      Registry tokens are optional when a registry permits anonymous reads. When
      required, set them in the host environment and pass them through at runtime:
      
      ```sh
      export CARGO_REGISTRIES_CORP_MIRROR_TOKEN='...'
      export CARGO_REGISTRIES_CORP_PRIVATE_TOKEN='...'
      
      docker run --rm -it \
        --env CARGO_REGISTRIES_CORP_MIRROR_TOKEN \
        --env CARGO_REGISTRIES_CORP_PRIVATE_TOKEN \
        --volume "$PWD:/workspace" \
        rust-dev-corporate:1.97.1
      ```
      
      Do not pass tokens as Docker build arguments or store them in the Cargo config.
      
      For a private dependency, use the stable registry name from the image:
      
      ```toml
      [dependencies]
      internal-library = { version = "1.2.3", registry = "corp-private" }
      ```
      
      Ordinary dependencies need no changes:
      
      ```toml
      [dependencies]
      serde = "1"
      ```

      `Cargo.lock` identifies crates.io as the original source.
